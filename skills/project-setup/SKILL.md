---
name: project-setup
description: Khởi tạo một project code mới trong workspace (cấu trúc thư mục, README, git, build/test chạy được). Dùng khi được yêu cầu tạo project/app mới.
roles: [coder]
---
1. Tạo thư mục `projects/<tên>` trong workspace; không đụng project khác.
2. Chọn stack theo yêu cầu; nếu không nói rõ thì chọn đơn giản nhất chạy được.
3. Tạo README.md: mục đích, cách chạy, cách test.
4. Khởi tạo git (`git init`) và `.gitignore` phù hợp.
5. Viết code tối thiểu chạy được + 1 test; chạy build/test và ghi kết quả vào báo cáo.
6. Báo cáo: đường dẫn project, lệnh chạy, lệnh test, kết quả.
